# Gry Mieszka

Gry zrobione przez Mieszka.

Strona: https://mieszko.vibemaster.pl (oraz https://bartibo.github.io/mieszko/)

## Jak dodać nowy projekt

1. Utwórz folder, np. `gra2/`, wrzuć do niego plik gry i zrzut ekranu `screenshot.jpg` (najlepiej 1280×800).
2. Skopiuj kartę gry w głównym [index.html](index.html) i podmień link, obrazek, tytuł i opis.
3. Zrób commit i push do gałęzi `main`. Po minucie gra będzie na https://mieszko.vibemaster.pl.

## Gry

- [Morski Łowca](gra1/wedkarz.html): łowienie skarbów w trzech światach, postęp zapisuje się w przeglądarce (localStorage).

Używaj w ścieżkach linków względnych (`img/statek.png`, a nie `/img/statek.png`),
żeby gry działały zarówno pod adresem github.io, jak i pod własną domeną.
