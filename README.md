# Gry Mieszka

Gry i projekty tworzone przez Mieszka i jego tatę.

Strona: https://bartibo.github.io/mieszko/

## Jak dodać nowy projekt

1. Utwórz folder, np. `kosmiczna-gra/`, i wrzuć do niego `index.html` (oraz resztę plików gry).
2. Dodaj kartę z linkiem do folderu w głównym [index.html](index.html).
3. Zrób commit i push do gałęzi `main`. Po minucie gra będzie pod adresem
   `https://bartibo.github.io/mieszko/kosmiczna-gra/`.

Używaj w ścieżkach linków względnych (`img/statek.png`, a nie `/img/statek.png`),
żeby gry działały zarówno pod adresem github.io, jak i pod własną domeną.
